# 离线营养数据子集

本目录用于比赛 Docker 镜像中的离线营养估算。已逐条通过 FoodData Central API 核验的条目使用 `USDA FoodData Central` 和真实 `FDC-...` ID；数据按每 100 克记录，核验日期为 2026-07-13。

`USDA-derived estimate` 表示尚未逐条完成 FDC ID 核验，或中国复合调味品没有直接等价基础条目。数值由公开 USDA 食品值和常见产品标签范围派生，`source_id` 使用 `LOCAL-...-V1`。这类值不能宣称为 USDA 原始检测值，后续应逐条核验并用真实 FDC 条目、合法获得的《中国食物成分表》或产品实测数据替换。

字段固定为能量、蛋白质、脂肪、碳水化合物、膳食纤维、糖和钠。糖字段在 USDA 条目缺失时使用可用总糖值；无法可靠获得的数据记为 0，并由菜谱覆盖率与可信度共同提示，不作为医学检测结果。

营养估算误差主要来自菜谱中的“适量/少许”、体积换算、可食部、烹饪吸油和份数推定。系统必须显示可信等级及缺失食材，不得把估算值描述为实验室精确结果。
