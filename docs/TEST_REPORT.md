## 四、重点验收场景

请求：

```json
{
  "messages": [
    "4个人吃午餐，先推荐4道菜。",
    "我不吃鸡蛋，其他菜尽量别动。"
  ]
}
```

验证结果：

- 返回 4 道菜；
- 用餐人数识别为 4；
- 菜品数量识别为 4；
- “不吃鸡蛋”识别为忌口；
- 未将“不吃鸡蛋”识别为过敏；
- 推荐结果不命中鸡蛋相关食材；
- 菜单变化模式为 `minimal_revision`；
- 菜单替换数量为 1；
- 营养结果按 4 人计算；
- 低风险场景使用本地营养评审。

首页三轮最终验收：

- 第 1 轮：`v1`，4 道菜；
- 第 2 轮：`v2`，识别鸡蛋忌口，最小修改；
- 第 3 轮：`v3`，识别高血压、减脂和清淡要求，未出现明显辣味菜；
- 回滚第 1 版后生成 `v4`，当前鸡蛋忌口仍保留。
