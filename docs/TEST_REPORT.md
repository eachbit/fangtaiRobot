## 四、重点验收场景

请求：

```json
{
  "messages": [
    "4个人吃午餐，先推荐4道菜。",
    "我不吃鸡蛋，其他菜尽量别动。"
  ]
}
```

验证结果：

- 返回 4 道菜；
- 用餐人数识别为 4；
- 菜品数量识别为 4；
- “不吃鸡蛋”识别为忌口；
- 未将“不吃鸡蛋”识别为过敏；
- 推荐结果不命中鸡蛋相关食材；
- 菜单变化模式为 `minimal_revision`；
- 菜单替换数量为 1；
- 营养结果按 4 人计算；
- 低风险场景使用本地营养评审。

## 五、公网性能

公网批测每类场景执行 3 次，最大响应时间如下：

| 场景 | 最大响应时间 |
| --- | ---: |
| 重点多轮验收 | 0.56 秒 |
| 复杂人数表达 | 3.26 秒 |
| 高血压和减脂营养评审 | 4.28 秒 |
| 四大一小离线解析 | 0.41 秒 |
| 普通清淡晚餐 | 3.69 秒 |

普通场景优先使用本地规则，复杂场景可以使用外部模型辅助。外部模型超时或不可用时，系统保留本地推荐和营养结果。
