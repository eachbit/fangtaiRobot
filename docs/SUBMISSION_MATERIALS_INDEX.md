# 方太个性化膳食规划 Agent 项目提交材料

版本：2026-08-22

## 一、项目简介

方太个性化膳食规划 Agent 面向家庭膳食推荐场景，融合用户健康档案、自然语言需求和官方菜谱数据，为用户生成可验证、可解释的个性化菜单。

系统重点解决以下问题：

- 多人用餐时的菜品数量和健康需求；
- 过敏、忌口和口味约束；
- 多轮对话中的菜单保留和局部修改；
- 整桌营养估算与风险提示；
- 官方菜谱真实性和接口响应效率。

## 三、系统交付内容

### 1. API 服务

```text
公网地址：http://47.116.110.131:8000
健康检查：GET /api/health
推荐接口：POST /api/recommend
```

### 2. 网页演示

```text
http://47.116.110.131:8000/
```

网页支持用户档案选择、对话输入、菜单展示、约束查看、营养结果、评分卡和审计任务展示。

### 3. 核心数据

系统使用本地官方菜谱库、用户健康档案和对话用例。推荐结果中的菜品名称均来自官方菜谱库，不由外部模型自由生成。

### 4. 部署方式

系统支持 Python 直接运行、Linux systemd 常驻运行和 Docker 容器运行。外部模型通过环境变量配置，不写入源代码和镜像。

## 四、核心功能

- 官方菜谱检索与真实性校验；
- 过敏、忌口、健康目标和口味约束；
- 多人用餐和复杂家庭人数表达；
- 菜品数量、餐次和场景识别；
- 整桌营养估算和人均营养结果；
- 多轮上下文保持；
- 菜单版本历史和回滚；
- 可选外部模型辅助；
- 外部模型超时后的本地规则回退；
- API、网页和 Docker 交付。

## 五、交付安全

- API Key、服务器密码和环境变量不写入代码仓库；
- 健康档案和官方数据文件按交付要求单独提供；
- 推荐菜品、硬约束和营养数值由本地逻辑校验；
- 外部模型只用于结构化约束辅助和营养评审话术；
- 外部模型不可用时，推荐接口仍可使用本地规则完成服务。
